extend windows (spacedesk replacement)

spacedesk discontinued its browser viewer, so it cannot run on Linux. Same result, smoother: on the PC install Sunshine and a free virtual display driver (e.g. "Virtual Display Driver" by VirtualDrivers on GitHub). Windows then has a real extra monitor. In Sunshine pick that monitor; on the tablet open Moonlight and choose "Desktop".
Settings work on the tablet's own screen. From here you can see the status below.
